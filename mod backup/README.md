# Mod backups

English | 中文

## English

- `timetable_idget_1/` — TPF2 `idget` export mod
- `tpf3_timetable_bridge/` — TPF3 bridge mod

Both folders are copies of the corresponding mod sources and are provided here
**for code sharing and backup only**. Normal users should download the mods from
their official distribution channels:

- TPF2: Steam Workshop (Timetable AutoFill Program Assist Tool)
- TPF3: in-game mod.io Mod Hub (Timetable AutoFill)
